- README.md에는 목차만 둔다(맨 위 소개·도구 표·설치는 그대로) — 기능 설명은 `docs/<도구>/<기능>.md` 한 파일에 한 주제, 한 문장 한 줄.
- 새 문서는 README의 `## 목차` 경로 이름순 자리에 한 줄을 넣는다(끝에 덧붙이지 않는다).
- README에 글을 더하던 쪽과 부딪히면 그 글을 알맞은 `docs/<도구>/<기능>.md`로 옮겨 푼다(README에 되돌려 넣지 않는다).
- `tests/repo/docs_test.go`가 목차와 README 목차 밖 줄 수 상한을 본다 — 상한을 올리는 것은 사람 결정이다.
