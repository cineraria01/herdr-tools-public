# herdr-sync: 충돌과 푸는 법

판정은 파일·구역·키마다 3-way다.
기계마다 `~/.local/state/herdr-sync/base.tsv`에 herdr-sync가 마지막으로 써 준 값의 cksum이 있다.

| 그 기계 값 | 판정 |
|---|---|
| 맥 값과 같다 | 같음 |
| base와 같다 (그 기계가 손대지 않음) | 맥 값으로 씀 |
| 내용은 맥 값과 같고 실행 권한만 다르다 | 씀 (권한만 맞춘다) |
| 그 밖 (그 기계에서 따로 고쳤거나, 처음이라 base가 없는데 다름) | 충돌: 쓰지 않고 `충돌 <기계> <경로> (n줄 다름)` |

- 맥 값이 맞으면 `herdr-sync --take <기계>:<경로>`.
- 그 기계 값이 맞으면 `herdr-sync --pull <기계>:<경로>`. 맥 실제 파일이 바뀌고 저장소에 모인다 — 이 실행은 그 기계만 돌고, 다른 기계에는 다음 보통 배포(`herdr-sync`) 때 퍼진다(지금 함께 퍼뜨리려면 기계 인자로 적는다: `herdr-sync --pull <기계>:<경로> <기계> <다른 기계>…`).
- 맥 ↔ 저장소도 같은 규칙이다(base는 맥 `~/.local/state/herdr-sync/repo-base.tsv`, 열쇠는 맥 경로, 셋째 칸은 저장소 경로 — 줄을 옮기면 base 없음으로 본다.
  셋째 칸이 없는 옛 base에서 저장소 쪽이 없으면 맥 파일을 지우지 않고 충돌로 멈춘다).
  저장소에서 지워진 것은 맥에서 백업으로 옮기고 `맥 지움 <경로> (저장소에서 지워짐)`. 모으다 실패하면 그 저장소에서 이번에 쓴 경로만 되돌리고 멈춘다.
  둘 다 바뀌었으면 `충돌 저장소 <경로>`를 찍고 아무 데도 쓰지 않고 멈춘다.
  맥 값을 남기려면 `--take repo:<경로>`, 저장소 값을 남기려면 `--pull repo:<경로>`.
- push가 거절되면 멈추고, 다음 실행이 그 저장소의 「지난번 push 못 한 커밋」을 다시 보낸다.
- 바이너리 줄은 base 대신 bin.tsv의 마지막으로 깔아 준 sha와 견준다 — 따로 바뀌었으면 `충돌 <기계>:.local/bin/<도구> (따로 바뀜)`, 덮기는 `--take`([바이너리 줄](binary-lines.md)).
- 덮거나 지운 것은 그 기계의 `~/.local/state/herdr-sync/bak/<YYYYMMDD-HHMMSS>/<경로>`에 남는다.
- 쓰기는 임시 파일에 쓰고 cksum을 맞춘 뒤 바꿔 넣는다.
  실행 권한은 맥 값을 따른다.
