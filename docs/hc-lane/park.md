# hc-lane park (주차)

- **주차** `hc-lane park [<한 줄>]`(2026-11-20 — 먼저 띄운 레인이 선행을 기다리며 자리를 쥐었다): 레인 작업 폴더에서, 커밋 안 된 변경·진행 중인 rebase가 없을 때 HEAD를 `refs/park/<레인>`(지금 값에 lease — 2026-11-21 hc-lane-go-start: 제출 가지 `lane/<레인>`과 다른 이름이라 병합기·clean이 주차를 제출로 읽지 않는다)에 올리고 이 레인 임대(`HC_LANE_LEASE` 값일 때만)를 같은 `--atomic` push로 놓은 뒤 「주차」 사건. 결과는 원격을 다시 읽어 본다(응답 유실 — 같은 줄을 다시 돌리면 같은 값으로 모인다).
  종료 0 주차, 1 실패, 3 원격 없음. 「주차」는 wait·watch에서 착지·제출처럼 정상 끝이다.
  뒤의 `hc-lane clean`은 그 가지를 「주차됨」으로 지운다.
  띄울 때 `--resume`이면 새 작업 트리를 `refs/park/<레인>`(없으면 옛 판이 주차한 `lane/<레인>`)에서 만들고 upstream을 `origin/<기본>`으로 둔다(없으면 안 띄움).
  hc-fill이 선행 착지 뒤 이것으로 다시 띄운다(아래 hc-fill 「주차」).
  `--help`·`-h`는 아무것도 하지 않고 사용법(종료 2), `-`로 시작하는 다른 인자는 「알 수 없는 인자」(종료 1, 주차 안 함)이고 `-`로 시작하는 글은 `hc-lane park -- <글>`로 준다(2026-11-23 park-help-guard — `park --help`가 도움말 대신 실제로 주차했다).
