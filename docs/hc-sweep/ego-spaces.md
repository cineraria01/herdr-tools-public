# hc-sweep: ego 작업 공간 쓸기 (주인 없이 남은 브라우저 공간 닫기)

- 2026-11-27 ht-sweep-ego-spaces — 사용자 「에고 브라우져도 자동 정리 한번씩 하면 좋겠네」. 에이전트는 일이 끝나면 `finish()`로 공간을 닫지만, 끊긴 세션이 닫지 못한 공간은 남는다. 업계 이름은 유휴 자원 회수(idle reaper): 주인이 사라졌거나 오래 안 쓴 것만 주기적으로 닫는다.
- **도는 곳**: 쓸기 바퀴마다(다른 쓸기와 같은 주기), `ego-browser`가 PATH에 있는 macOS 기계. 없으면(리눅스 등) 아무것도 안 한다.
- **ego를 스스로 띄우지 않는다**: `ego-browser`를 부르면 앱이 안 떠 있을 때 앱을 띄운다. 그래서 먼저 `ps -axww -o command=` 한 번으로 앱 본체(`…/Contents/MacOS/ego lite`)가 떠 있는지 보고, 떠 있을 때만 부른다.
- **목록**: `ego-browser nodejs -e` 안의 `listTaskSpaces()` 한 번(상한 20초). 상한을 넘김·종료 코드 0 아님·출력을 못 읽음·칸이 빠짐(`id`·`name`·`createdBy`·`ownership`·`taskId`·`profileId`·`recentTabTitles` 가운데 하나라도)은 모름이다 — 그 바퀴는 건너뛰고 기록을 바꾸지 않는다.
- **후보**: `createdBy`와 `ownership`이 둘 다 `agent`이고 이름이 빈 글자가 아닌 공간만. 사용자 공간(`user`)·사용자에게 넘긴 공간(`agentDelegatedToUser`)·에이전트가 남긴 페이지를 사용자에게 준 공간(`ownership` `user`)·모르는 값은 모두 사용자 것으로 보고 건드리지 않는다.
- **「안 쓰는 중」 판정**: 목록에 마지막 사용 시각이 없어 hc-sweep이 스스로 적는다. 공간 id마다 지문(이름·`createdBy`·`ownership`·`taskId`·`profileId`·탭 제목 목록의 sha256 앞 16자)과 그 지문이 된 때·마지막으로 본 때.
  - 처음 본 공간·지문이 바뀐 공간·id가 다른 공간에 다시 쓰인 것(지문이 다름)은 「지금」부터 센다 — 기록 없이 처음 돌 때 이미 쌓인 것을 바로 닫지 않는다.
  - 마지막으로 본 때가 문턱보다 오래면(hc-sweep이 한참 안 돌았다) 그 사이를 그대로로 세지 않고 다시 처음 본 것으로. 그래서 문턱은 쓸기 주기(launchd 5분)보다 길게 둔다 — 짧으면 바퀴마다 처음으로 돌아가 아무것도 안 닫는다.
  - 지문이 손잡이 `sweep_ego_idle`분(기본 120) 그대로이고, 그 바퀴의 `ps`에 `ego-browser` 명령 프로세스가 없으면 닫는다(돌고 있으면 그 바퀴는 안 닫음).
- **닫기**: 공간마다 `ego-browser nodejs -e` 한 번(상한 20초) — 목록을 다시 보아 지문 칸이 그대로일 때만 `await (await taskSpace(<id>)).finish({ keep: [] })`, 닫혔는지는 그 영수증의 `closedSpace`로 본다(닫은 직후 목록에는 잠깐 남을 수 있다). ego-browser는 `console.log`를 표준 오류로 내므로 표식 줄(`HCSWEEP `)은 두 쪽에서 찾는다. ego가 사용자 탭·출처 모르는 탭을 스스로 지킨다(남으면 공간이 안 닫힌다).
  - 닫힘 → 기록에서 뺀다. 그 사이 바뀜 → 다시 처음부터 센다. 공간이 남음 → 「지켜짐」으로 적고 지문이 바뀔 때까지 다시 시도하지 않는다.
  - 닫기 호출이 상한을 넘기거나 답을 못 읽으면 모름 — 그 바퀴의 남은 닫기는 부르지 않는다(막힌 ego가 바퀴를 늦추지 않게).
- **알림**: 닫은 것이 있을 때만 운영 사건 `hc-ego-idle` 한 번 — `ego 작업 공간 <n>개를 닫음(<기계>, 그대로 <문턱>분 넘김): <이름> (#<id>, <분>분 그대로), …`. 줄은 쓸기 기록에도 찍힌다.
- **기록**: `~/.local/state/hc-sweep/ego-spaces.json`(id → 지문·때·지켜짐). 깨진 기록은 처음 봄으로 읽는다(시계가 다시 시작할 뿐 — 일찍 닫지 않는다). 쓸기 잠금(sweep.lock) 안에서만 쓴다.
- **미리 보기**: `hc-sweep --dry-run`은 닫을 것만 말하고 닫지도 기록하지도 않는다.
- **끄기**: `hc-fill knob set sweep_ego_idle 0 --why …`(또는 손잡이 설정 파일) — 0이면 `ps`도 목록도 안 읽는다. 시험·별난 자리는 환경 `HC_SWEEP_EGO`(`off`면 안 함, 다른 값이면 그 경로).
- 하지 않는 것: ego 프로세스를 끄거나 다시 띄우기, 쿠키·캐시·프로필, 탭을 직접 닫는 낮은 길(CDP), 레인·터미널과 공간을 잇는 이름 규칙.
- 시험: `cmd/hc-sweep/ego_test.go`(문턱 전·넘김·지문 바뀜·남의 공간·ego 안 뜸·명령 없음·모름·명령 도는 중·지켜짐·닫기 직전 바뀜·막힘·오래 못 봄·dry-run·가짜 ego-browser 실행 파일).
