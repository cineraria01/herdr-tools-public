# hc-fill: 기계 능력

- **기계 능력**(같은 결정 — 웹 배포가 필요한 레인이 railway CLI 없는 기계에 떠 막혔다): 지시문의 `필요: railway, xcode` 줄(목록 머리 `-`·`*` 허용, 능력 이름은 `a-z 0-9 _ -` 낱말을 쉼표로 — 다른 글이 섞인 줄은 문장으로 보고 안 셈, 여러 줄이면 합침)과 설정 `machine-has <기계> <능력,…>`을 대조해 능력을 다 가진 기계에만 띄운다(감사 줄은 그 레인 기계라 안 봄).
  가진 기계가 (`--only` 안에) 하나도 없으면 대기로 두고 「막힘 <레인>: 필요 … — 그 능력을 가진 기계가 없다」를 찍고 주인 지휘에 `hc-lane report 막힘` 한 번(`~/.local/share/hc-fill/need.tsv` — 같은 레인·능력이면 바퀴마다 되풀이하지 않음), `ls` 비고 「필요 <능력> — 가진 기계 없음」.
  설정에 능력을 더하면 다음 바퀴에 뜬다.
