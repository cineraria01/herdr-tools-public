# hc-fill: 줄 고치기 (edit)

- **줄 고치기는 `edit`** (2026-11-22 — 지휘가 주차 줄의 선행을 바꾸려고 `rm` → `add`를 해 주차 표식이 풀려 준비 커밋을 버리고 새로 뜰 뻔했다): 대기열 잠금 안에서 선행(4)·기계(5)·지시문(3)·우선(13) 칸만 바꾼다.
  `-`는 비우기.
  `--brief`는 대기(`wait`, 주차 포함) 줄만 — 새 사본을 `briefs/added/<레인>.md`에 두고, `--then`으로 「## 이어서:」가 붙은 지시문은 거절.
  `--priority`는 `prio`와 같다(떠 있고 이미 병합기 큐에 냈으면 큐 메타도).
  없는 레인·잘못된 값은 종료 2, 대기열 그대로.
