# hc-fill: 지시문 복사

- **지시문은 add 때 복사된다**: 내용을 `~/.local/share/hc-fill/briefs/added/<레인>.md`로 복사하고 대기열에는 그 경로를 적는다(launchd로 도는 `watch`는 macOS 개인정보 보호로 `~/Documents` 등을 못 읽는다).
  그 뒤 원본을 고쳐도 반영되지 않는다(`rm` 뒤 다시 `add`).
  못 읽거나 빈 지시문은 `add`가 거절하고, `run`도 띄우기 전에 실제로 읽어 보아 못 읽으면 「실패 <레인>: 지시문을 읽지 못함(<까닭>)」을 찍고 띄우지 않는다(대기로 남음).
