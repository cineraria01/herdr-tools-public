# hc-fill: 멈춘 레인

- **까닭**(2026-11-25 ht-lane-hang-detect): 한 레인이 「1 shell still running」을 기다리는데 검증 프로세스가 없어 1시간 넘게 아무도 몰랐고, 다시 지시하자 「Ionizing… (20m 39s)」로 도구 호출 없이 20분 넘게 멈췄다(지휘가 Escape로 끊어 풀었다).
- **어디서**: `run` 바퀴(완료 뒤 멈춤 알림과 같은 자리, `cmd/hc-fill/hang.go`). 대상은 대기열 up 줄의 주소에 그 레인 이름 터미널이 살아 있을 때만이다 — 감사 줄(`audit=…`)은 빼고, 사람·병합기 터미널은 대기열에 없고, 주소가 재사용되면 이름이 달라 빠진다. 끊긴 기계는 건너뛴다.
- **(a) 「생각 중」에 멈춤**: hc 상태 working이고 화면 마지막 진행 표시 줄(`✻ Ionizing… (20m 39s · …)` 꼴)의 시간이 손잡이 `hang_min`분(기본 15, 0이면 이 기능 끔) 넘고, 그 줄 위 화면이 `hang_min`분 넘게 그대로이고, 터미널 프로세스 자손에 도구 셸이 없을 때.
  - 도구 셸 = 명령 줄에 `shell-snapshots`가 든 자손(Claude Code Bash 도구 셸, `hc-lane` `lane.wait_procs` 기본과 같은 표식). MCP 서버도 작업 트리를 cwd로 쓰므로 cwd로는 세지 않는다.
  - 도구 셸이 있으면(긴 포그라운드 검증 등) 멈춤이 아니다. 화면이 바뀌면 처음부터 센다.
  - 한계: 셸 없이 오래 걸리는 도구(큰 MCP 호출 등)도 진행 표시만 돌고 화면이 그대로라 `hang_min`분 뒤 끊길 수 있다 — 한 시간에 한 번이고 레인이 이어 간다.
- **(b) 배경 셸이 소리 없이 죽음**: hc 상태가 idle·done이고 화면의 **마지막** 턴 끝 줄(`✻ Crunched for … · 1 shell still running` 꼴, 머리 글자는 `hc-lane` `lane.wait_line` 기본과 같다)에 「N shell(s) still running」이 있는데 도구 셸 자손이 3분 넘게 없을 때. 그 줄 아래에 `Interrupted` 줄이 있으면 보지 않는다(끊긴 턴은 끝 줄을 안 찍어, 그 줄은 옛 턴 것이다).
  옛 턴 줄·본문 인용에 남은 같은 글은 보지 않는다(완료 뒤 감사 기다림 화면에 흔히 남는다). 원격 기계는 `hc exec`로 `ps`를 읽는다. 셸이 살아 있으면 알리지 않고 종류 `b-live`로 적는다.
- **배경 일 기다림**(2026-11-26 ht-advise-done-noreport — 턴이 끝나(done) 「1 shell still running」으로 마지막 검증을 기다리던 레인이 「끝났는데 보고 없음」으로 58분 울렸다): `hc-fill state`·`advise`·`status`는 `hang.tsv`에 그 레인·주소의 `b-live` 줄이 있으면 단계를 「작업 중(done)」 대신 「배경 일 기다림(done)」으로 센다. 파일이 10분 넘게 안 바뀌었으면(바퀴가 안 돎·`hang_min` 0) 모름이라 쓰지 않는다. 셸이 죽었으면 종류 `b`라 그대로 알린다.
- 상태가 working·idle·done이 아니면(blocked·error·모름) 화면을 읽지 않는다.
- **알림**: 그 레인 주인 지휘에 막힘 한 번(키 `hf:<레인>:hang-<a|b>:<처음 본 초>`, 받은편지 레인은 모든 지휘). 글에 근거(분·주소)와 다음 명령(`hc read <주소>`, (b)는 `hc send` 한 줄)이 든다.
- **조치 (a)만**: 손잡이 `hang_esc`(0·1, 기본 1)가 1이면 `hc keys <주소> esc` 한 번 뒤 「앞 요청이 N분 멈춰 끊었다 — 마지막 지시를 이어서 하라」를 보낸다. 한 레인에 한 시간에 한 번(`<상태 폴더>/hang-esc.tsv`, 보내기 전에 적고 한 시간 넘은 줄은 그때 버린다), 했는지는 알림 글과 일지(`hang-esc`)에 남는다. (b)는 알리기만 한다.
  - 기본 켬으로 둔 까닭: 세 조건(진행 표시·화면 그대로·도구 셸 없음)이 모두 맞아야 하고, 지휘가 손으로 하던 것과 같고, 끊어도 대화는 남아 레인이 이어 간다. 끄기: `hc-fill knob set hang_esc 0`.
- **기록**: `<상태 폴더>/hang.tsv`(레인 주소 종류 처음 본 초 화면 지문) — 바퀴마다 의심 줄만 다시 적는다. 화면·hc get·ps를 못 읽으면 모름으로 알리지 않고 지난 기록을 둔다.
- 시험 `cmd/hc-fill/hang_test.go`(진행 표시 시간 읽기, 도구 셸 없음 판정, 한 시간 한 번 제한, 감사·이름 다른 터미널은 대상 아님).
